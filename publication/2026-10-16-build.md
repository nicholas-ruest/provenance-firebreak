# Provenance Firebreak build — 2026-10-16

## Capability

Provenance Firebreak is a 22-crate Rust software-supply-chain incident system that reconstructs temporal deployment lineage, recalls analogous incidents with RuVector, computes a split-conformal upper-risk bound, chooses a least-disruptive quarantine preserving tier-0 payments, seals the decision with RVF, and verifies recovery.
